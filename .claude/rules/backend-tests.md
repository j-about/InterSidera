# Backend test rules (pytest)

- Markers are declared and strict: `unit`, `api`, `conformance`, `slow`. `make check` runs `pytest -m "not slow"`; `make test` runs everything.
- pytest must not inherit `.env` or the CI environment: the autouse `clean_env` fixture in `conftest.py` deletes every `SKYAPI_*` variable before each test, and fixtures build `Settings(...)` explicitly (`data_dir=tmp_path_factory.mktemp("data")`, `auto_fetch=False`, `ephemeris="de440s.bsp"`). Session-scoped fixtures run before `clean_env`, so they never construct `Settings`: they receive `kernels_dir` and `CachePaths` directly. Never rely on ambient env, with one documented exception: `INTERSIDERA_TEST_DATA_DIR` (not `SKYAPI_`-prefixed) may redirect the test kernel directory, default `<repo>/data`.
- The Makefile passes `--env-file` only on run targets; check and test targets stay hermetic so `make check` passes from a clean clone.
- `de440s.bsp` covers 1849-2150 only: never request a date outside it in a test. Moon-frame tests must include a pre-2426 date (Skyfield #952 regression). The test kernel set (`de440s.bsp`, `pck00011.tpc`, `moon_de440_250416.tf`, `moon_pa_de440_200625.bpc`, about 46 MB) is provided by the session fixture `kernels_dir` in `tests/conftest.py`, which verifies the registry pins and downloads a missing file through `skyapi.data.download` (network once; CI restores it from a cache).
- No network in tests beyond that kernel fixture: no de441, no MPCORB, no Nominatim, no Horizons. Use committed fixtures (`tests/fixtures/`) and excerpts under `tests/fixtures/excerpts/`: every excerpt is under 1 MB and starts with an in-file provenance header (leading `#` lines: source URL, license, fetch date, what was kept; JSON files carry a top-level `_provenance` object), has a `[[excerpts]]` entry in `data_files.toml` and is described in `excerpts/README.md`. Builders strip the header lines before parsing.
- Shared helpers live in `tests/support/` (`pythonpath = ["tests"]`); fixture modules there are wired through `conftest.py`, never through `pytest_plugins` in a nested conftest.
- `slow` tests that need the full data files skip with the explicit reason "full data files not present in DATA_DIR: run `make data`" when the files are absent: a data-availability condition documented in `docs/testing.md`, not a gate bypass. Local subset runs use `--no-cov` (pytest-cov's warning about unimported modules would fail under `filterwarnings = error`).
- `TestClient` is used as a context manager (`with TestClient(app) as client:`) so the lifespan runs; the API is exercised through the client, never by calling route functions directly. API tests use the session fixture `api_client` (`tests/support/fixtures_api.py`: an excerpt-backed `DATA_DIR` assembled by `assemble_data_dir`, settings from `default_settings().model_copy(update=...)` with typed values and the rate limit effectively off, readiness awaited by `wait_ready`, which fails fast on a `detail`). The function-scoped `client` has an empty `DATA_DIR` and answers `503 starting`: use it for that case only. Special cases (progress, degraded, 429) build their own app with `api_settings_for(data_dir, **overrides)` and `create_app(settings, registry=...)`; the 429 test uses `rate_limit_rps=0.01, rate_limit_burst=2` and `TestClient(app, client=("203.0.113.9", 4444))`. `@given` tests never use function-scoped fixtures.
- `filterwarnings = ["error"]`: a third-party warning is fixed at the source or silenced with a targeted `ignore:<message>:<Category>:<module>` entry carrying a comment and a backlog line; never a blanket ignore.
- The OpenAPI snapshot test compares `render_openapi(create_app(settings))` with `docs/openapi.json` and tells the reader to run `make types`.
- Coverage (from M1): >= 90 % on `skyapi/astro` and `skyapi/catalogs`; 100 % on `astro/quaternions.py` and `catalogs/formats.py`. hypothesis property tests for canonicalization, time conversions and the SKYS round-trip.
- Conformance tests assert Horizons tolerances (planets and Moon within 2 arcsec, stars within 1 arcsec) and are marked `conformance`; `slow` for anything that needs the full catalogs.
- `--import-mode=importlib`; `tests/**` may ignore ANN rules, nothing else.
- Never skip, weaken, delete or xfail a test to make a gate pass.
