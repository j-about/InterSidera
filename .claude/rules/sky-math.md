# Sky mathematics rules (pure modules, 100 % coverage)

- `frontend/src/sky/math/*` (`typed`, `vec3`, `quaternion`, `frames`, `interpolation`, `properMotion`, `refraction`, `time`, `stars`, `lines`), `frontend/src/state/url.ts`, `state/clock.ts`, `state/frames.ts`, `astro/quaternions.py` and `catalogs/formats.py` are pure and dependency-free: no Babylon, no React, no store, no I/O, no Skyfield, no globals (ESLint forbids the imports). `sky/math/**` and `state/url.ts` carry 100 % line, branch, function and statement coverage (brief l.294, plan D88); their tests load the shared fixtures under `backend/tests/fixtures/` through `src/test/fixtures.ts`.
- Numeric idiom (plan D71): fixed tuples `Vec3 = [number, number, number]` and `Quat = [x, y, z, w]`; bulk storage in typed arrays read through `at(a, i)` (throws `RangeError` out of range) and `load3`/`load4`/`store3`; every kernel takes an `out` parameter and allocates nothing; angles between unit vectors through `atan2(|a x b|, a . b)`, never `acos`; no `?? 0` fallbacks (a dead branch would break the 100 % gate).
- The frontend never computes an astronomical position from first principles (brief l.41). Allowed client-side operations: rotate by the backend horizon quaternion, apply linear proper motion with backend vectors, interpolate backend samples, first-order annual aberration with the backend observer velocity (stars only, c = 173.1446 au/day), and the refraction formula on Earth validated against Skyfield within 1 arcmin above -1 degree.
- Refraction (plan D73, backlog B-50): the single forward formula is `refraction.ts::apparentAltitudeDeg(hTrue, factor)`, a Saemundsson seed followed by two Bennett corrections, scaled by `factor = (P / 1010) * (283 / (273 + T))` from `refractionFactor(elevM)`, zero below -1 and above 89.9 degrees. Both star shaders mirror it line by line (range guards included); the bodies layer and the debug hook call it. Change one, change all four, and re-run the fixture parity tests (measured 0.057 arcmin, asserted <= 1 arcmin).
- Quaternions use the Hamilton convention: `v_enu = q * v_icrf * q^-1`, stored `[x, y, z, w]`. Consecutive samples are sign-continuous (positive dot product) so slerp never takes the long way; interpolation renormalises directions.
- Skyfield's altaz matrix is left-handed north-east-up: `quaternions.py` swaps rows x and y (NEU -> ENU) before the matrix-to-quaternion conversion and is tested against `altaz()` azimuth (`atan2(E, N)`) and altitude (`asin(U)`).
- The ENU -> Babylon mapping (left-handed, Y-up: East -> +X, Up -> +Y, North -> +Z; azimuth from north through east, clockwise from above) exists only in `frames.ts`: `enuToBabylonMatrix()` is the permutation P (determinant -1) that every sky mesh carries as its frozen world matrix (ADR-0009), `cameraRotationFor(az, alt) = { x: -alt, y: az, z: 0 }`, and `screenToDirection`/`directionToScreen` are the pure projections; unit tests cover az=0 -> +Z, az=90 -> +X, alt=90 -> +Y. Shaders and layers contain no swizzle. `alt` is clamped to +-89.99 degrees, `fov` (vertical, degrees) to [1, 120].
- Body samples are interpolated with cubic Hermite and Catmull-Rom tangents (one-sided at the ends, directions renormalised, NaN scalars propagated); the horizon and equinox quaternions are slerped on the CPU in float64 and uploaded as uniforms; no rotation accumulation on the GPU. Extrapolation beyond a window uses its two boundary samples.
- Time: TT Julian Date (float64) is canonical; `tt_minus_utc_seconds` from the current frame converts to UTC; proleptic Gregorian with astronomical year numbering; our own Julian Date utilities, never moment/dayjs. `state/clock.ts` derives `tt` from the control block `{ mode, speed, ttAnchor, wallAnchorMs }`; the engine calls it with `Date.now()`.
- `state/frames.ts` is the pure fetch policy (plan D76): `buildRequest` (OBS-7 rounding, `step_s` clamp through `step_class`), `requestKey`, `decide` (fetch, prefetch at 70 %, snapshot mode at <= 4 Hz, swap, drop, extrapolate), `windowFromResponse` (shape check, echoed grid), `evaluate`; `shapeKey` (the request without `tt`) identifies in-flight and backing-off requests so a moving alignment bucket never re-issues them; `COVERAGE_GUARD_D` (1e-6 day), `clampInsideCoverage` and `boundedRequest` handle a 422 at a coverage bound (the API rounds `tt` to 1e-8 day, so the advertised bound itself is refused). Test both speed signs, snapshot mode, the 1e-8 day alignment tolerance and both coverage bounds with a fake clock.
- `state/url.ts`: named parameters per UX-2, defensive parsing (unknown or invalid values fall back to defaults), rounding (coordinates 0.01 deg, alt/az 0.01 deg, fov 0.1 deg, tt 1e-6 day, speed and maglim 0.1), stable serialization order, default-valued keys omitted except `body, lat, lon, elev, t, az, alt, fov`.
- `stars.ts` owns the magnitude limit per field of view, the pixel radius, the brightness and the B-V colour stops shared by the shaders and the debug hook; `lines.ts` owns the great-circle, small-circle and azimuth-arc generators writing into preallocated `Float32Array`s.
- `formats.py` (SKYS v1): magic `SKYS`, `version u32`, `count u32`, `epoch_tt f64`, `flags u32`, then packed columns `dir f32[3n]`, `pm f32[3n]`, `mag i16[n]`, `bv i16[n]` (32767 unknown), `hip u32[n]`, little-endian, sorted by magnitude ascending; round-trip tested with hypothesis and mirrored byte-for-byte by `api/catalogs.ts::parseSkys` (zero-copy views at offsets 24, 24+12n, 24+24n, 24+26n, 24+28n).
- Shaders: GLSL for WebGL2 and WGSL for WebGPU, both implementing the same star rule `dir(t) = normalize(dir + pm * years)`, then aberration, then the horizon rotation, then optional refraction; no point primitives (four vertices per star, corner from the vertex index).
- Babylon imports (in `sky/engine/` only) use `@babylonjs/core/<module>` subpaths; `sky/math` imports nothing from Babylon.
- Fixture parity tolerances: stars <= 1 arcsec (propagation <= 0.1 arcsec), bodies <= 1 arcmin for `step_s <= 3600` and `|speed| <= 3600` with a 1 arcsec regression bound on the Hermite interpolation, slerp <= 0.01 arcsec, refraction <= 1 arcmin on both fixture tables, the Sun of the Greenwich window within 1 arcsec of the Horizons row.
