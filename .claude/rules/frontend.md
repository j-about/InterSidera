# Frontend rules (React 19, TypeScript 6, Vite 8, Tailwind 4)

- TypeScript strict with `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `verbatimModuleSyntax`, `erasableSyntaxOnly`: use `import type`, no enums, no namespaces, no parameter properties. ESM only. Typed-array reads are `number | undefined`: use `at()`/`load3()`/`load4()` from `sky/math/typed.ts` or a guard, never `!`, never `as number`.
- ESLint runs `strictTypeChecked` + `stylisticTypeChecked`: `!` non-null assertions and floating promises are errors. Guard instead (`if (!el) throw ...`), and `void` or `await` every promise (`void i18next.init(...)`). `signal.aborted` narrows to `false` across awaits: read it through a function (`const aborted = () => signal.aborted`).
- React 19: function components and hooks only; `ref` as a prop (no `forwardRef`); no `useEffect` for derived state; the React Compiler stays off. UI components (`ui/`) contain no astronomy math and never import `sky/math` (ESLint enforces it). The store, the frame controller and the engine factory are props of `App` and `SkyCanvas`, so tests inject fakes and Babylon never runs under jsdom.
- Store ownership (plan D80): one zustand vanilla store (`state/store.ts`, `subscribeWithSelector`) shared by React (`useStore` from `zustand`, `useShallow` from `zustand/react/shallow` for object selectors) and the engine (selector subscriptions with `shallow`). The engine owns time (`Date.now()` in `SkyEngine.tick`, mirror published at <= 2 Hz through `publishTt`); the camera controller writes `view`; React never selects `view` at animation rate and never drives the canvas. Slice types live in the import-free leaf `state/types.ts`.
- Browser timers: `@types/node` is in the app project, so use `window.setTimeout` / `window.clearTimeout` / `window.setInterval` in browser code (a bare `setTimeout` types as `NodeJS.Timeout`).
- Debug hook guard: `debug/skyDebug.ts` is reached only through `await import('../debug/skyDebug')` inside the literal condition `if (import.meta.env.DEV || import.meta.env.MODE === 'e2e')` (plan D86); never import it statically, never reference `__sky` elsewhere in `src/` (the production build is grepped for the string). The `#engine=webgl2|webgpu` hash override is read under the same condition and never serialized.
- Every user-visible string goes through `t()` with a key in both `i18n/en.json` and `i18n/fr.json` (UX-1). `scripts/check_i18n.mjs` fails on missing or unused keys; template keys use a literal prefix (`t(\`constellations.${abbr}\`)`).
- Tailwind CSS-first: configuration lives in `styles/app.css` (`@import "tailwindcss"`, `@theme`, `@custom-variant night`, base rules under `@layer base`). No `tailwind.config.js`; class names are complete literal strings, never concatenated (choose between whole strings in a helper); class order is enforced by prettier-plugin-tailwindcss.
- No storage APIs: no cookies, `localStorage`, `sessionStorage` or IndexedDB (OBS-8). The URL query string is the only persisted state (`state/url.ts` codec, `state/urlSync.ts` writer at <= 2 Hz with rounded floats, hash preserved).
- Privacy rounding: latitude and longitude to 0.01 degrees before any API call (`api/client.ts::observerQuery`, OBS-7); the exact position leaves the browser only toward the geocoder the user explicitly queried (M4).
- Only `import.meta.env.VITE_*` reaches the client; never mirror a `SKYAPI_*` value into a `VITE_*` variable.
- API types come from the generated `api/schema.d.ts` (never hand-edited); `api/client.ts` is the single fetch layer (typed `getJson`/`getBytes`, `ApiProblem`, `NetworkError`, retry with backoff, `pollHealth`); `api/catalogs.ts` loads the catalogs with `cache: 'no-cache'` and ETag comparison.
- Babylon.js: import from `@babylonjs/core/<module>` subpaths only, and only under `src/sky/engine/` (ESLint enforces both); never the package root, `Legacy/legacy` or the UMD `babylonjs`. Side-effect imports live in `sky/engine/babylon.ts` (WebGL set) and `sky/engine/webgpu.ts` (lazy chunk), one comment per import. Shaders are separate `.glsl`/`.wgsl` twins imported with `?raw`; never `glslangOptions`/`twgslOptions`.
- The render loop belongs to `SkyEngine` (`engine.runRenderLoop`): no allocation per frame, typed arrays and preallocated buffers (`FrameEval`, out parameters), React re-renders never touch the canvas; sky meshes keep ENU geometry under the frozen world matrix P from `sky/math/frames.ts` (ADR-0009).
- Dates: never parse negative years with `Date`; use `Date.UTC` + `setUTCFullYear`, keep TT Julian Date canonical, format years with an explicit sign and a custom formatter (`sky/math/time.ts`).
- Nominatim (M4): submit-only, at most one request in flight and >= 1 s apart, `<meta name="referrer" content="strict-origin-when-cross-origin">`, attribution displayed, handle 403/429 with a message.
- Accessibility (UX-4): keyboard-operable controls with visible focus, ARIA names (`aria-label` on the canvas, `role="status"` on the splash), no state conveyed by colour alone, `prefers-reduced-motion` respected; jsx-a11y must stay clean.
