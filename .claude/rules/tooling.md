# Tooling rules (Makefile, CI, configs, version files)

- Version policy: latest stable at project start, re-checked at each milestone; never pre-releases. `package.json` uses caret ranges except `typescript: ~6.0.3` (ADR-0001) and the exact pair `vitest` / `@vitest/coverage-v8` `4.1.11` (the provider peers the exact vitest version; bump both in one commit; Vitest 5 waits for jest-dom #738, ADR-0004 amendment); `pyproject.toml` uses `>=x.y,<next-major`, 0.x tools bounded at the minor (`ruff>=0.16.5,<0.17`). Both lockfiles are committed.
- Frozen until the ADR revisit trigger fires: TypeScript stays 6.0.x, npm stays the bundled 11.x, Python stays 3.14 (`requires-python = ">=3.14,<3.15"`), the two npm `overrides` (`eslint-plugin-jsx-a11y -> eslint`, `openapi-typescript -> typescript`, ADR-0002) stay. Never `--legacy-peer-deps`. Every new dependency needs an ADR.
- `.node-version` = `24` and `.python-version` = `3.14` (root and `backend/`, because uv does not search beyond the project boundary). CI reads `node-version-file: .node-version` relative to the repository root.
- Makefile: `SHELL := /bin/bash`, `.SHELLFLAGS := -eu -o pipefail -c`, no `.ONESHELL`; backend commands are `uv run --directory backend ...` (never `--project`, never `cd`); Node commands go through `fnm exec --using=$(CURDIR)/.node-version`; npm through `npm --prefix frontend`; never a root `npx`.
- `--env-file $(CURDIR)/.env` is passed only on run targets (`dev-api`, later `data`, `up`); check, test and types targets never load `.env`, so `make check` is hermetic from a clean clone.
- `make check` mirrors CI and CI mirrors `make check`: any step added to one is added to the other in the same commit; the one CI-only step is the frontend job's `npm run build` plus the `__sky` grep (plan Q1: brief l.421 lists `make check` without a build, `make build` carries the same grep). The contract drift gate is `git ls-files --error-unmatch` then `git diff --exit-code` on `docs/openapi.json` and `frontend/src/api/schema.d.ts` (plain `git diff` ignores untracked files). `npm run test` is `vitest run --coverage` (the 100 % gate on `src/sky/math/**` and `src/state/url.ts` lives in `vite.config.ts`, no Makefile flag).
- Builds: `npm run build` (production; `make build` then runs `! grep -rl "__sky" frontend/dist/assets`) and `npm run build:e2e` = `tsc -b && vite build --mode e2e` (`make build-e2e`, the only build with the debug hook); `make e2e: build-e2e` runs `npm run e2e -- --project=chromium-desktop --project=chromium-mobile`. The CI frontend job runs the same grep after `npm run build`.
- CI `e2e` job (`needs: [backend, frontend]`, `timeout-minutes: 30`): checkout@v7, setup-node@v7 with the npm cache, `astral-sh/setup-uv@20cfd1bf945f4377ade1205e4dbc17946fc9a30d # v10.0.1` (setup-uv publishes no floating major tag after v7, so it is the one action pinned to a full tag/SHA), `uv sync --locked`, `npm ci`, `actions/cache/restore@v6` of `data/` keyed on `data_files.toml` + `catalogs/*.py` + `data/caches.py`, `sky-data fetch --only de440s pck00011 moon_tf moon_bpc hipparcos hyg ngc ngc_addendum stellarium_modern stellarium_description d3_bounds` (never MPCORB or de441; `/health` then reports `degraded` with `missing: ["mpc"]`), `sky-data build-caches`, `actions/cache/save@v6` under `if: always()`, `actions/cache@v6` of `~/.cache/ms-playwright` keyed on the lockfile, `npm exec -- playwright install --with-deps chromium` (never a root `npx`), `npm run build:e2e`, the two-project run, `upload-artifact@v7` (`if: ${{ !cancelled() }}`, `if-no-files-found: ignore`) of `test-results` and `playwright-report`.
- `scripts/check_i18n.mjs` is syntax-checked with `node --check` and formatted by a config-free prettier run (`SCRIPTS_PRETTIER` in the Makefile: `--no-config --print-width 100 --single-quote`, mirrored as a CI step). ESLint is not used on `scripts/`: ESLint 10 refuses files outside its base path (`frontend/`). `scripts/*.py` are formatted and linted with the backend ruff config through the explicit `--config` form (`uv run --directory backend ruff format --check --config pyproject.toml ../scripts` and `ruff check --config pyproject.toml ../scripts`): ruff resolves configuration per file and the repository root has none.
- Coverage gate (D39, brief l.294): the pytest line of `make check` carries `--cov=skyapi.astro --cov=skyapi.catalogs --cov-report=term-missing:skip-covered`, followed by three `coverage report` lines (`src/skyapi/astro/*` >= 90, `src/skyapi/catalogs/*` >= 90, `quaternions.py` + `formats.py` = 100). CI mirrors all four lines.
- `THIRD_PARTY_NOTICES.md` is generated (`make notices` = `python -m skyapi.tools.render_notices --out`), listed in `GENERATED`, and gated like the contract files (`check-contract: types notices`, `git ls-files --error-unmatch`, `git diff --exit-code`); CI runs the same two commands.
- CI restores the test kernels (`data/*.bsp data/*.tpc data/*.tf data/*.bpc`) with `actions/cache/restore@v6` before pytest and saves them with `actions/cache/save@v6` under `if: always()`, keyed on `backend/src/skyapi/data/data_files.toml`; on a miss the session fixture downloads them (de440s and three small NAIF kernels only, never de441 or MPCORB).
- `make data` is a run target (`PYRUN`, loads `.env`): `sky-data fetch` then `sky-data build-caches`. `make notices` is hermetic (`PY`).
- `frontend/package-lock.json` must contain the `linux-x64-gnu` optional binaries (`@rolldown/binding-linux-x64-gnu`, `@tailwindcss/oxide-linux-x64-gnu`, `lightningcss-linux-x64-gnu`): development is aarch64, CI is x86-64. Regenerate from a clean `node_modules` if one is missing. `lockfileVersion` is 3. `.npmrc` has `engine-strict=true`.
- Vite 8 vocabulary only: `build.rolldownOptions` (never `rollupOptions`), `output.codeSplitting` (never `manualChunks`), `oxc` (never `esbuild`). The `codeSplitting.groups` are `babylon-webgpu` (`Engines/(webgpuEngine|WebGPU)`, `ShadersWGSL`, `Audio`; priority 20; reached only through the dynamic import in `sky/engine/createEngine.ts`) and `babylon` (the rest of `@babylonjs/core`; priority 10); check the built manifest after a Babylon bump. Vitest 4: `test.projects` (never `workspace`), explicit `test.exclude`, `coverage.exclude` listing `**/*.test.ts` and `src/test/**`. Prettier Tailwind plugin key: `tailwindStylesheet: "./src/styles/app.css"`.
- `@vitejs/plugin-basic-ssl` is enabled only for `vite dev` in development mode (not preview, not test), so Playwright runs over plain HTTP on 4173. Playwright projects: `chromium-desktop`, `chromium-mobile`, `webkit` (`testIgnore: /webgpu\.spec\.ts/`) and `chromium-webgpu` (`channel: 'chromium'`, `launchOptions.args: ['--enable-unsafe-webgpu', '--use-webgpu-adapter=swiftshader']`, `testMatch` on that spec only); `webServer` reuses running servers outside CI.
- TypeScript 6 defaults `types` to `[]`: `tsconfig.app.json` lists `vite/client`, `vitest/globals` and `node` (the fixture loader); `tsconfig.node.json` lists `node` with `lib: ["ES2023", "DOM"]` so the Playwright specs can type `window.__sky`; no `baseUrl`.
- CI: `actions/checkout@v7`, `actions/setup-node@v7`, `astral-sh/setup-uv@20cfd1bf945f4377ade1205e4dbc17946fc9a30d # v10.0.1` (no floating `v10` tag exists upstream), `actions/cache@v6` (later `upload-artifact@v7`, `docker/setup-buildx-action@v4`, `docker/build-push-action@v7`); `permissions: contents: read`; no `pull_request_target`; `SKYAPI_AUTO_FETCH=false` and `SKYAPI_EPHEMERIS=de440s.bsp` in the workflow env; CI never downloads de441 or MPCORB and never contacts Nominatim or Horizons.
- The backend CI job runs `setup-node` and caches `~/.cache/pyright-python` because the PyPI `pyright` is a Node wrapper that downloads the npm package on first run.
- `.env.example` documents every `SKYAPI_` variable with safe defaults and comments on their own lines; paths are relative to `backend/`; `SKY_DATA_DIR` (M7) stays commented until compose exists.
- Generated files (`docs/openapi.json`, `frontend/src/api/schema.d.ts`, both lockfiles) are marked `linguist-generated` in `.gitattributes` and never hand-edited.
- `frontend/eslint.config.js` `no-restricted-imports` blocks (plan D90): `@babylonjs/*` only under `src/sky/engine/**`; no Babylon, React, zustand, i18next or node modules inside `src/sky/math/**` and `src/state/{types,url,clock,frames}.ts`; no `sky/math` imports from `src/ui/**` and `App.tsx`.
