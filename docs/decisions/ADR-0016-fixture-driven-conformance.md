# ADR-0016: Fixture-driven conformance: Horizons fixtures, delta-T injection and the test kernel set

- Status: Accepted
- Date: 2026-09-24 (records decisions taken at M1 on 2026-09-03, M2 on 2026-09-06, M3 on 2026-09-06 and M5 on 2026-09-17; recording form)

## Context

The brief wants `tests/fixtures/` to hold "machine-generated cases (generator script committed, sources cited): JPL Horizons reference values for a set of bodies, observers and dates, and Skyfield outputs for the same cases" (l.179), pytest accuracy against Horizons within 2 arcsec for planets and the Moon and 1 arcsec for stars (l.180), vitest loading "the same fixtures" for the TypeScript propagation, interpolation, proper-motion and refraction code (l.181), `de440s.bsp` downloaded once into a cached test data directory (l.400), and a CI that "never downloads de441 or MPCORB and never contacts Nominatim or Horizons" (l.428). Only test excerpts under 1 MB with a provenance header may be committed (l.325). The acceptance invariants (l.569) must run through the API. Two facts constrained the design: Skyfield's bundled daily IERS table covers 1973-01-02 to 2027-01-23 only, so at 1900, 1969, 2050 and 2140 Skyfield's and Horizons' delta-T models diverge (plan R37); and Moon and Mars observers need three more NAIF kernels than de440s (backlog B-31).

## Options considered

1. Live Horizons queries in the tests. Rejected: l.428, and the SSD API throttles (R33).
2. Skyfield-versus-Skyfield only. Rejected: no independent reference for the accuracy claim of l.262.
3. Committed machine-generated fixtures produced by a committed generator, regenerated by hand at most once per milestone. Chosen.
4. Delta T at the far epochs: the builtin timescale everywhere (rejected: the comparison would test the delta-T model, not the geometry) or Horizons' quantity 30 injected as a constant delta T (chosen, D37).

## Decision

Records plan rows D37, D38, D40, D50, D66, D88 and D133.

- D37 (generator): `scripts/generate_fixtures.py horizons` queries the Horizons API with `TIME_TYPE=TT`, quantities 1, 2, 4, 9, 10, 13, 20, 24, 30, 32 and 45, Earth sites GEODETIC (WGS84), Moon and Mars sites CYLINDRICAL from our planetocentric vector; the builtin timescale serves 2000 and 2024 (inside the IERS table), quantity 30 is injected at 1900, 1969, 2050 and 2140 (TDB - UT1 before 1962, TDB - UTC after, so UT1 = UTC is assumed where Horizons' UT1 - UTC is <= 0.03 s); ICRF quantities are compared everywhere and Mars alt/az after tilting our planetocentric zenith to Horizons' planetodetic normal (0.2034 degrees at Jezero). The script refuses to run when the `CI` environment variable is set (l.588-591) and follows the SSD fair-use policy. `generate_fixtures.py skyfield` writes the three parity fixtures (`skyfield_stars.json`, `skyfield_frames.json`, `skyfield_refraction.json`) from our own core on de440s.
- D38 (kernels): the session fixture `kernels_dir` (`backend/tests/conftest.py` l.121; `INTERSIDERA_TEST_DATA_DIR`, the only ambient variable tests may read, default `<repo>/data`) verifies the four pinned kernels (`de440s.bsp`, `pck00011.tpc`, `moon_de440_250416.tf`, `moon_pa_de440_200625.bpc`, about 46 MB) against the registry and downloads a missing one through it; CI restores and saves them with `actions/cache` under `if: always()`; session fixtures never construct `Settings` and receive `kernels_dir` and `CachePaths` directly (helpers in `tests/support/`).
- D40 (excerpts): every other data set is exercised on committed excerpts under `backend/tests/fixtures/excerpts/`, each under 1 MB with an in-file provenance header, a `[[excerpts]]` registry entry and a README.
- D50 (refraction): `astro/refraction.py` mirrors Skyfield's `earthlib.refract` as the reference table, and `skyfield_refraction.json` is the frontend's parity source for `sky/math/refraction.ts`.
- D66 (API tests): the session fixture `api_data_dir` assembles an excerpt-backed `DATA_DIR` (the kernels symlinked, the excerpts under their registry names, a generated Stellarium description, a real cache manifest through `build_all`); `api_settings` derives from `default_settings().model_copy(...)` with the rate limit effectively off; `api_client` waits on `/health` and fails fast on a `detail` (`tests/support/fixtures_api.py` l.94-109); the l.569 invariants run through the API in `tests/conformance/test_invariants.py`.
- D88 (frontend parity): `frontend/src/test/fixtures.ts` reads the same JSON files with `node:fs` and structural guards; `npm run test` is `vitest run --coverage` with 100 % thresholds on `sky/math/**` and `state/url.ts`; the parity bounds are the measured facts (propagation <= 0.1 arcsec, apparent <= 1 arcsec, Hermite <= 1 arcsec, refraction <= 1 arcmin).
- D133 (orientation): `backend/tests/fixtures/device_orientation_cases.json` comes from `generate_fixtures.py orientation`, an independent plain-Python twin of the W3C matrix (worked examples, geometric poses, seeded round trips, compass and gimbal rows), loaded by `sky/math/orientation.test.ts` at 1e-9 / 1e-7 degree.

## Consequences

- Numbers of record (`docs/testing.md`): 30 conformance tests over 360 Horizons cases (six observers, six epochs, the Sun, Moon, planets and Pluto), ICRF directions within 0.011 arcsec, alt/az within 0.56 arcsec on Earth, 0.008 on the Moon and 0.0006 on Mars; frontend parity 0.007 arcsec (propagation), 0.655 arcsec (apparent), 0.253 arcsec (Hermite), 0.057 arcmin (refraction).
- A fixture regeneration is a reviewed change: every file carries `source`, `generator`, `generated_at`, the parameters and the raw request URLs (`backend/tests/fixtures/README.md`).
- The Mars-site tolerance stays 2 arcsec (B-36 reserved, never used: Horizons' IAU 2009 Mars pole agrees with `pck00011.tpc` within 0.017 arcsec at every epoch, ADR-0007).
- `make check` needs the network only for the four kernels on a clean clone (the fixture downloads them once), which the M6 clean-clone run records.

## Revisit trigger

- Skyfield ships a newer IERS table (the epoch policy of D37 is data-driven through `delta_t_coverage`, so only the recorded numbers change); Horizons changes its API or its delta-T policy; a fixture shape change (the frontend loader fails loudly).
