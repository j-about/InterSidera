# Data sources

Status: stub written at M0; completed at M1 (registry `backend/data/data_files.toml`, `sky-data` CLI, SHA-256 pins, `THIRD_PARTY_NOTICES.md`). The brief's list (`docs/brief.xml` l.303-334) was verified against the live sources on 2026-09-02; the table below is the corrected version and supersedes the brief where they differ (see `docs/plan.md` section 5 for the evidence).

Every file is downloaded by `sky-data fetch` into `DATA_DIR` (`SKYAPI_DATA_DIR`, default `../data` relative to `backend/`) with SHA-256 verification and resumable downloads; none is committed to the repository. Sizes are exact byte counts from HTTP `Content-Length` on 2026-09-02 unless marked approximate.

## Licensing policy (brief l.323-329)

- Third-party data is never committed. Allowed in git: test excerpts under 1 MB in `backend/tests/fixtures/excerpts/` with a source and license header and a `THIRD_PARTY_NOTICES.md` entry; the small factual CSVs authored for this project; machine-generated fixtures holding JPL Horizons values.
- `THIRD_PARTY_NOTICES.md` (generated from the registry at M1) lists every dataset with source URL, version or fetch date, license and attribution; the About screen renders the same credits (mandatory for CC BY-SA and OpenStreetMap).
- Catalogs derived from share-alike sources (HYG, OpenNGC, Stellarium) are served under the same license, declared in `/meta.catalogs.<name>.license` and `.attribution`; the build scripts being public satisfies the share-alike condition.
- Never add data, images, fonts or textures with an unknown or non-commercial license.
